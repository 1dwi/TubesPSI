# Detail Jumlah Dataset & Hasil Anotasi (Untuk Logbook)

Berikut adalah angka pasti (jumlah) dataset original dan hasil anotasinya untuk diisikan ke logbook:

## 1. Jumlah Dataset Original (Ori)
Total keseluruhan dataset mentah (original) yang dikumpulkan adalah **531 gambar**.

Rincian per kelas:
- **Daun Muda:** 295 gambar
- **Daun Menguning:** 149 gambar
- **Daun Tua:** 87 gambar
**Total Ori = 531 gambar**

## 2. Jumlah Hasil Anotasi
Semua gambar mentah berhasil dianotasi (diberi label kelas) 100%. Tidak ada data yang dibuang.

Rincian hasil anotasi per kelas:
- **Daun Muda:** 295 gambar
- **Daun Menguning:** 149 gambar
- **Daun Tua:** 87 gambar
**Total Hasil Anotasi = 531 gambar**

---

### *Catatan Tambahan (Opsional jika ditanya soal Augmentasi/Training)*
Dataset yang sudah dianotasi (531 gambar) ini dibagi menjadi:
- **Data Training:** 424 gambar (80%)
- **Data Validation:** 107 gambar (20%)
